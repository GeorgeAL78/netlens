First public release of **UniFi NetLens** — a self-hosted dashboard for a UniFi network.

**Usage** — traffic per device and per app with 5-minute charts and sessions; every number on a
screen comes from one source and adds up; local-network traffic shown separately; missing days
marked and filled from UniFi's daily per-device totals; views up to 90 days.

**Wi-Fi** — every device worst-signal-first; per device signal history, time per access point,
roams and a presence heatmap.

**Equipment** — gateway, switches and APs: CPU, memory, temperature, radio load, ports, uplinks.

**Threats** — blocked intrusions and firewall-rule hits with top sources, targets and rules.

**Also** — gateway/WAN strip, network events, device blocking, optional syslog listener for
blocked-ad counts, login, Unraid template.

Images: `gjergjk/unifi-netlens` and `ghcr.io/georgeal78/unifi-netlens` (amd64, arm64).
